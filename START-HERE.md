# 🚀 Quick Start - Run Locally

## For Keyword Density Calculator (Easiest!)

**No server needed!** Just open the file:

### Windows
1. Double-click `keyword-density.html`
2. Start analyzing!

### Mac
1. Double-click `keyword-density.html`
2. It will open in Safari
3. Start analyzing!

### Result
Your browser will open the keyword density calculator directly. Paste text or JSON and start analyzing immediately!

---

## For Full Website (With Server)

### Windows
1. Double-click `server.bat`
2. Browser opens automatically

### Mac & Linux
1. Open terminal in this folder
2. Run: `./server.sh`
3. Browser opens automatically

## 💡 Quick Tips

- **Keyword Density Calculator** works without server
- **Main website** needs server (run server.py or server.bat)
- Press Ctrl+C to stop server
- Default port is 8080
